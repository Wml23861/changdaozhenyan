# 第1章 清晨，神坛上那支笔自己动了

己酉年的春天来得比往年都要晚，三月甲辰日这一天的清晨，天边的鱼肚白才刚刚漫过黑瓦的屋檐，整个小镇还泡在灰蒙蒙的晨雾里没有醒透，

陈觉就已经穿戴整齐，净了手，焚了香，端端正正跪在了自家净室中央的蒲团上。

这间净室是他提前好几天就收拾出来的，桌椅挪到了墙角，地面扫了一遍又一遍，连窗纸上的浮灰都用湿布擦得干干净净，

妻子带着孩子们睡在东厢，临睡之前还嘀咕了他两句，说当家的你这是着了什么魔，大半夜的不睡觉，折腾这间空屋子做什么，

他只是笑了笑没有多解释，

有些事情在没有结果之前，解释得再多也是白搭。

说起陈觉这个人，方圆十里没有人不认识他，

他是个教了半辈子书的穷先生，自号鹤臞子，今年整整四十岁，膝下儿女绕了一圈，家里的米缸却三天两头见底，全靠着给镇上的蒙童讲些论语孟子，换几斗糙米几串铜钱勉强度日，

亲戚们提起他来总要摇头叹气，说这人读了一肚子的圣贤书，偏偏连自家的日子都过得紧紧巴巴，实在算不上什么出息。

他的日子确实过得清苦，

白天在村塾里教孩子们认字背书，嗓子喊得冒烟，傍晚回家还要帮着妻子烧火做饭，

几个孩子围着他要听故事，他就把白天讲的论语换成大白话再讲一遍，孩子们听得咯咯直笑，妻子在一边缝补衣裳，油灯烧到半夜，

这样的日子说不上好，也说不上坏，

只是夜深人静的时候，他一个人坐在灯下，总觉得心里空落落的，好像少了点什么。

可陈觉自己心里并不这么想，

他总觉得人活一世，吃穿好坏都是小事，真正要紧的是弄明白一件事，那就是人为什么活着，又为什么非死不可，

这个问题他琢磨了半辈子，问遍了能问的人，翻遍了能翻的书，得到的答案不是语焉不详，就是故弄玄虚，没有一个能让他打心眼里服气，

所以这几年下来，他的心思渐渐从圣贤书上，移到了那些谈玄说妙的道书上面。

去年冬天，他在县城的旧书铺里淘到一册残破的法本，里头记载着一门文昌笔录大法，

说得直白一些，就是摆下香案沙盘，请天上的神明降临坛场，借一支乩笔，把天机写在沙子上给人看，

他捧着那册书研究了整整一个冬天，把每一步仪轨都背得滚瓜烂熟，心里却始终半信半疑，总觉得这种请神降笔的路数，多半是旁人在故弄玄虚。

为了这一天，他照着法本上的要求，提前好几天就开始斋戒净身，荤腥不沾，酒水不碰，每天把净室打扫一遍，把要用的沙盘、乩笔、信香、烛台一样一样备办齐全，

有邻居撞见他去香烛铺子，还打趣他，说陈先生这是要给自己招个神仙女婿不成，

他也不争辩，只是拱拱手笑笑，心里却想，是真是假，总要试过才知道。

镇上的街坊邻居也听说了他近来迷上道书的事，

有人在背后笑话他，说陈先生书教得好好的，怎么想不开要去弄这些神神鬼鬼的东西，

也有人好心劝他，说咱们这种穷苦人家，安安稳稳过日子才是正经，那些神仙道祖的事情，哪里轮得到咱们来操心，

这些话传到他耳朵里，他也不恼，只是照旧备他的香案，抹他的沙盘。

"来吧，"陈觉跪在蒲团上，望着眼前抹得平平整整的沙盘，在心里默默念叨了一句，

"我今日倒要看看，这三炷香烧下去，究竟能请出个什么名堂来。"

三炷信香插进炉里，青烟笔直地升了上去，烛火在晨光里烧得安安静静，

他依着法本上记载的仪轨，一步不差地做下来，然后把那支柳木削成的乩笔轻轻架在沙盘上方，屏住呼吸，瞪大了眼睛。

起初的半炷香工夫，什么都没有发生，净室里静得能听见灯花爆裂的轻响，

陈觉跪在那里，膝盖渐渐跪得发麻，心里那点怀疑又开始冒头，

他甚至已经开始琢磨，待会儿收拾沙盘的时候，该怎么跟妻子交代这场徒劳，

人家天上的尊神日理万机，凭什么搭理你这么个连米缸都填不满的穷教书匠。

就在这个念头刚刚冒出来的时候，

那支笔，忽然动了。

不是被人扶着、被手带着的那种动，而是它自己稳稳地立了起来，笔尖落在细沙上，一笔一画，不快不慢，从容不迫，

就好像有一个看不见的人，正端端正正坐在案前写字。

陈觉的汗毛，唰的一下全都竖了起来，

他死死盯着沙盘，看着那支笔在沙面上游走，

写出来的第一行字，是一段名号，那名号长得吓人，一字一顿，笔笔清楚，字字端正，

写的是，南极天宫，青华上帝，大悲大愿，至圣至仁，降炁垂光，谈经演教，历持浩劫，度人无量天尊，无上道祖仙师。

陈觉读了一辈子书，道家典籍也翻过不少，当然知道这一串名号意味着什么，

书上说南极天宫是九霄之上的巍巍天宫，青华上帝是执掌救苦度人之职的至尊，这样的名号，绝不是什么山精野怪敢随口冒充的，冒充正神是要遭天谴的，

这是发下大誓愿、要度尽无量众生的那一位真正的大人物。

他的呼吸一下子就乱了，跪在那里连头都不敢抬，手心里沁出来的汗把衣角都打湿了一片，

脑子里翻来覆去只剩下一个念头，那就是今天请来的这位，来头大得超出了他半辈子的所有想象，大到他都不知道该怎么称呼，该怎么行礼，该怎么开口说第一句话。

那支笔却没有停，

写完名号之后，它既没有寒暄，也没有客套，更没有写什么尔等虔诚朕心甚慰之类的场面话，只是略微一顿，随即笔锋一转，在沙盘上写出了一句让陈觉怎么都想不到的开场白。

那位存在开口的第一句话，竟然是骂人，

这跟他想象的完全不一样，他原以为神仙降坛，开口不是讲些晦涩难懂的玄理，就是来几句高深莫测的谶语，

谁能想到这位至尊一开口，就像一个憋了一肚子火的老长辈，劈头盖脸先把天下人训了一顿。

祂骂的不是陈觉，而是普天之下所有学道的人，

沙盘上的字迹一行接着一行，越写越快，越写越急，像是憋了千百年的一番话，终于找到了一个可以倾倒的出口，

那句话写的是，我看这世上学道的人，表面上一个个都在用功，可他们走的路子，其实早就全都走歪了。

陈觉跪在清晨的烛光里，看着这行字，大气都不敢出，只觉得那字里行间有一股说不出的威严，隔着一方沙盘，都压得人抬不起头来，

窗外不知谁家的公鸡叫了一声，接着是远处断断续续的狗吠，整个小镇正在晨光里慢慢醒过来，

谁也不知道这间小小的净室里，正在发生一件了不得的大事。

当时的他还不知道，从这一刻起，这位顶着青华上帝尊号的存在，会在这个小小的坛场上停留整整三年，

三年里祂不传符咒，不教丹方，不讲那些神神秘秘的秘传口诀，翻来覆去只讲两个字，

而这两个字，后来会变成一部五万多字的经书，会变成一条让凡人直登仙界的堂堂大路。

当然，这些都是后话了，

此刻的陈觉，只是跪在渐渐亮起来的晨光里，看着那支自己写字的笔，在心里反反复复地念叨着同一句话。

"完了，"他咽了口唾沫，只觉得嗓子眼里发干，

"今天请来的这位，是个真大佬，是那种名号写全了能铺满半个沙盘的大佬，我陈觉何德何能，一个连束脩都收不齐的穷先生，居然把这样的人物请到了自家的小屋里，这要是传出去，怕是整个县城都要轰动了。"

他正这么胡思乱想着，那支笔却又动了，沙面上簌簌作响，下一行字已经呼之欲出，

老人接下来要骂的话，一句比一句戳心，一句比一句诛心，

而陈觉很快就会发现，这些话骂的虽然是天下人，却句句都像是在说他自己。
