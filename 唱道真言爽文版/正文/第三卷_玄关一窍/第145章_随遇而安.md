# 第145章 随遇而安

陈觉等着老人替他指一处山居，乩笔却在沙上顿住，慢慢写：“古人随遇而安。”

他盯着那个遇字，方才想好的柴门、菜畦、窗前一段瘦竹还在，山中没有学生扯着嗓子背错书，也没有人隔着门问他钱米，连他想象中的松风都比院里的风懂事。

盘中又写：“虽遇毒蛇猛兽，与之同居，亲若兄弟，况同类之人乎？”

陈觉将蒲团往案边拉近了些，抬头道：“先生，弟子问的是寻个清静处，怎么连毒蛇猛兽也来了，若真住到一处，夜里谁还睡得着？”

盘中落字：“子欲择地，皆因自己学问浅薄，无大主张，无大包容，无大涵养。”

这句话才落，今晨赴会以前那一幕便回来了，妻子端着畚箕站在堂屋门口，灰盆夹在臂弯里，右脚进不来，左脚又叫门坎别着，他正在收拾学生的旧字课，嘴上先埋怨：“晚一步扫能怎样，没见这里正忙着么？”

他一只手还扶在字课上，墨沾了指腹，那句话已经出了门，收是收不回来了，他只好把纸一抽，妻子没防着，灰盆磕在门框上，扑起一小股灰。

“你要帮忙就好好帮，抽什么纸？”妻子偏头躲开，灰却落在她鬓边，她把畚箕往地上一顿，“成日在屋里讲清静，门口这点地方倒越堆越满。”

陈觉拿袖口去擦她的手背，妻子正换手，袖子擦了个空，他又不好再追着擦，只低声道：“我不是要赶你，方才那句话说得急了些。”

妻子当时只看见他杵在门口，便把灰盆塞给他，“拿着，别拿眼睛替我出力，灶门口还有一半，我扫完这一堆就来收。”

灰盆外壁滑，陈觉两手抱住才没叫它翻下去，盆底留着灶膛的余温，隔着薄衫熨在腹前，妻子已经从门后拿起扫帚，转身去了灶房。

他端盆跟过去，先把盆搁在灶门边，没有捧着盆来回跑，妻子见他踩到细灰上，鞋底一滑，扶了他一把，随即又松手：“四十岁的人了，走两步路还要墙帮忙，去，把那条长凳挪开，底下积了半个月，你每日吃饭倒看不见。”

陈觉道：“我每日要教书，还要抄字课，哪有闲眼专看凳子底？”

妻子把扫帚横过来，“我没叫你专看，如今叫你挪，你挪不挪？”

他弯腰拖凳，凳脚刮着砖地，刺啦一声，柜后觅食的母鸡咯咯跑开，妻子护住灰堆，骂的是鸡，陈觉却闭紧了嘴，一句也不敢往自己身上认。

乩笔续写：“见俗子，闻俗语，气怦怦然辄为之动，思得一清静之区，离群索居，方惬所愿。”

沙上接写：“具此胸襟，将何适而可，吾子过矣。有度量人，有学问人，决不如此。”

陈觉脸上仿佛又叫那股灰扑了一下，今晨他若真把自己那张书案当成只许自己清静的地方，妻子端盆进门便先成了打扰，经文问的哪里是山居，分明先问他在家中怎样待人。

沙上写：“彼以逆来，我以顺受，彼以嗔至，吾以喜当。”

他没有再去抬嘴角，只想起今晨后来的事，妻子叫他倒灰，他端起灶门边那只盆，道：“今日这盆灰算我的，你歇一会儿。”

妻子道：“盆是家里的，灰也是家里的，你倒一回怎么就算你的，裤脚先拍一拍，别等一会儿带到学生的字课上。”

陈觉低头，右边裤脚果然白了一片，他抬脚拍了两下，又顺势甩了甩鞋尖的灰，那只布鞋本就松，竟叫这一甩脱在门坎外，灰也扑了自己一鞋面。

妻子看了一眼，竟笑出声来，他起初还绷着，后来自己也忍不住，俯身拾鞋时道：“这倒好，灰没有出门，先叫鞋替我送了一程。”

“你要没事做，先把鞋穿稳，”妻子把扫帚往墙边挪了挪，“那条凳子别急着放回去，底下湿，等干了再挪。”

他穿妥鞋，端灰去了墙根，妻子在后头嘱咐：“后园那棵葱才冒头，别又给我压死了，上回你泼洗菜水，一泼半畦都趴着。”

“我倒去墙根，不碰你的葱。”陈觉应完，见她没有走，又补了一句，“我晓得哪一畦，不用你领着。”

妻子道：“晓得就好，上回你也说晓得，结果鞋上沾着泥，回来还赖鸡踩的。”

他张口要问哪一回，妻子已提着补好的袖套去了东厢，他只好蹲下身，把灰慢慢拨到浮土松处，没有压住葱叶，也没有再把这盆灰说成替谁做的功德。

案上的沙盘没有催他，等他回神才写：“幽兰生于萧艾之中，未尝自别于萧艾，而芬芳自吐，行者顾而爱之。”

陈觉提起笔，先在幽兰二字下点了一点，随即又拿笔杆把那点墨晕开，今晨妻子说他四十岁还要墙帮忙，他嘴上没辩，心里早把教书、抄字课排了一串，好像这些名目排出来，鬓边沾灰的人便该低他一头。

他索性把笔搁下，“先生，弟子若真把自己当成那枝兰，只怕闻不见什么香，先学会挑旁边都是些什么草了。”

盘中只添了四个字：“未尝自别。”

陈觉把那一笔歪斜的墨留在纸上，没有换纸重抄，学馆窗外有人赶着鸡走过，他没有关门，只把被风掀起的纸角重新压好。

沙上续写：“鹤立鸡鹜之中，未尝自标风韵，而仪度蹁跹，自有凌霄之志。”

陈觉读到凌霄之志，背脊自然直了，又想起家中那只母鸡绕回来啄砖缝，妻子拿扫帚轻轻赶它：“去去，这里没你的米，灰里翻得再细，也翻不出一顿饭。”

他听完，直起来的背又弯回去录字，风韵两个字没有注，凌霄也没有注，只把未尝自标四字写得比别处慢，写完一看，那一竖仍收得太长，像是不肯安分地待在行里。

等他洗净笔，盘中已写：“古之得道者，往往有投入魔宫，为魔眷属，德性熏陶，魔王稽首，敬爱交至。”

陈觉将这一行看了两遍，先前山居里除了松风便没有第二个人，此刻那处幻想忽然挤进许多人，有来借柴的，有来寻鸡的，还有站在门口问他米价的，他往哪里躲，那些人仿佛都能找到门。

他忙把眼睛收回纸上，“先生，弟子连妻子喊两声都要分个先后，何况同魔眷属住在一处，这段古人事，弟子只能照录，不敢拿来比今日扫了一回灰。”

乩笔没有替他添一句称赞，只将最后一句写完：“凶魔尚可化诲，亦何患于人哉？”

陈觉录罢，学馆笔录上兰字旁有一点晕墨，鹤字的一竖又出头，都是他今日留下的，他没有拿刀刮净，也没有另誊一张好看的夹在经稿里。

门后的旧字课已经压不住风，他寻来装字课的窄木匣，将干纸竖着放进去，剩下一小叠便用镇纸压平，学馆那把扫帚则从纸后头拿出来，斜倚在门边，明日进学馆的人伸手就够得着。

他没有再替自己挑一座山，散会以后，仍沿原路回家，张屠户正在院门口等着，见他便从怀里取出纸包：“今年秋后应补的那一份束脩，我卖了粮，今日给你凑齐了，你点点，别又只说往后不急。”

陈觉把纸包接过，照数点清，在束脩账上写明收讫，没有多收，也没有无故抹账，张屠户又道：“石头还照旧来，他在家说先生如今背书不只看错不错，还看他肯不肯自己改。”

“他肯来，我明日便照旧教，”陈觉把收账的纸条递给他，“你也带一句，今日那篇字还没改完，别叫他只知道束脩清了，功课也清了。”

张屠户笑着去了，妻子从抽屉里取出另一个装着五粒麦的小纸包，放到小幺儿手心：“你夏天收的五粒麦，如今该下种了，秫秸还在墙根，你自己还认不认得地方？”

小幺儿早已跑出去，半截秫秸歪在墙脚，他扶正以后，用指头挖出五个小坑，妻子跟在后头道：“坑别太深，一粒一个窝，盖松土，水只润一回，别拿瓢把种子冲出来。”

陈觉蹲在旁边，没有替他种，只把他挖得过深的那一处垫回些土，五粒麦逐粒落下去，小幺儿盖完土，又逐一数过：“五个窝，五粒，谁也没有少。”

过了几日，四处先露出针尖大的青，最后一处迟了一日，也顶开薄土，小幺儿蹲在墙根数了两遍，回头喊：“爹，五棵都出来了，最晚那棵也没赖在土里。”

陈觉放下手里的字课，走过去看了，没有拿五棵麦芽去比灵胎，也没有替它们算一年后该收几穗，只把歪倒的半截秫秸往旁边挪开些，免得挡住新叶上的日头。
