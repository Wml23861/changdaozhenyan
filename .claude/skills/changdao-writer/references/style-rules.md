# 《唱道真言》爽文版·创作规范与验证清单

本文件是 changdao-writer 技能的审查依据。所有规则的源头是
`唱道真言爽文版/资料/00_作品说明与连载大纲.md`，冲突时以大纲为准。

## 一、排版硬规范（每条违反都必须修正）

1. 不能有连续句号收尾的短句连用，短句一律用逗号并成长句。
2. 段落开头句必须有逗号；单句成段且段内无逗号的短段，只作节奏顿点单发使用，不得连续两段及以上连用。
3. 一句完整话不能只有一个逗号加句号就结束，句子要有足够的成分。
4. 全文不出现破折号、省略号等各种特殊标点符号（含 ——、—、–、……、…、直角引号、Markdown 符号）。
5. 对话内容正常用引号引起来（直角双引号 " "），可单独成段但不强制全部单独成段。
6. 每章正文 2500 字以上（不含首行标题，含标点），逻辑与标点使用正确严谨。
7. 段落长度适配手机阅读（番茄小说等平台）：叙事段不超过 80 字，对话与讲经段不超过 100 字，经文原文段不超过 100 字，任何段落不得超过 150 字。超限时在语气停顿、动作切换、说话人转换、句意边界处拆段。引语跨段拆分时每段都用完整引号（每段开头前引号、段尾后引号，各自闭口，符合网文平台读者习惯），不得增删改动任何文字。
8. 每段结尾必须用句号或问号收束（引语段在引号内收束），禁止以逗号、顿号悬空收尾；长流水句在一段之内完成，不跨段拖尾。引出下一段对话的提示语（如"老人写道"）段尾用冒号。每章句末标点（句号、问号）总数与逗号总数之比不低于一比十二，低于此值视为一逗到底，必须返修。
9. 开场铁律（2026-10-15 三轮返修后定稿）：正文第一段禁止出现日历报时（"正月""二月"至"腊月""冬月"及"X月过了一半/末了"等月份字样，"个月"表时长除外），开场先进场景、动作、对话或物件；时间靠物候自报（柳芽、槐花、麦花、蝉鸣、开镰等），节令只在有剧情功能时出现（元宵灯市、清明上坟、端午粽子、寒食不动火）；动笔前与前后各两章比对，相邻章不得同词、同意象打头。

## 二、文件与格式规范

- 路径：`唱道真言爽文版/正文/第NNN章_标题.md`，章号三位数字补零。
- 首行：`# 第N章 标题`（Markdown 一级标题，章号为普通数字，标题与文件名一致）。
- 正文除首行外无任何 Markdown 符号。
- 同步在 `唱道真言爽文版/资料/原文对照.md` 追加本章覆盖的原文条目。

## 三、文体指纹（从第1至8章成品提炼，新章必须同构）

- 叙事：第三人称贴陈觉视角，夹叙夹议，叙事人偶尔跳出来说"这些都是后话了"式的预告。
- 句法：以逗号串联的长流水句为主（平均句长 75 至 110 字，最长句 150 字以上），标点只有逗号、句号、问号、引号、冒号。
- 语言：现代白话掺说书人口吻，用词生活化（米缸、束脩、蒲团、乩笔、沙盘），绝不出现现代器物与网络梗。
- 对话：青华老人的话写在沙盘上，用"笔锋落沙""祂写道"等引出；人物口语直接、带火气，不说教。
- 结构：开篇承接上章钩子，中段一到三个具体场景，章尾留钩子（未发生的冲突、将至的转折、悬起的疑问）；开场段写法遵守第一节第 9 条开场铁律。
- 比喻：只用农耕、教书、市井生活圈内的意象（水面泥沙、菜谱、年礼杂糖、墙角的草），不用科幻、军事、工业意象。

## 四、改编红线（违反即重写）

1. 原文教义不增不改不曲解，讲解章严格对应原文段落。
2. 剧情演绎只为把道理演明白，不编造与原文相悖的功法、神异。
3. 新增人物与支线必须最终收束到原文脉络上（如陈贯三、罗一纯出自跋文，不是虚构空降）。
4. 青华老人不传铅汞火候的具体操作，只讲炼心，任何"泄露秘法"式情节都是红线。

## 五、既定事实表（连贯性硬约束）

- 陈觉：四十岁，私塾先生，道号鹤臞子，脾气大、念头杂、最大的毛病是不信。
- 青华老人：青华上帝，度人无量天尊，己酉年三月甲辰日降坛，七日一会，只讲炼心两字。
- 已建立设定：文昌笔录大法（县城旧书铺淘得）、七岁梦兆、城隍庙作揖、周老友（争论对象）、妻子（从不信到将信将疑）、几个孩子、米缸常见底、静坐功课（每日一炷香）、"不怕念起只怕觉迟"。
- 时间线：第一卷第5至12章为"三年回廊"倒叙单元，演降坛后第一年的"初不之信"到"有进步有实得"。
- 人称与称谓：叙事用"祂"指青华老人，用"他"指陈觉；沙盘上写字不用"说"，用"写道""笔锋一落"。

## 六、人工特性验证清单（三层全部通过才算完成）

### 第1层 机器校验（脚本）

运行 `scripts/check-chapter.ps1`，错误必须为 0，警告应逐条评估并尽量清零。

### 第2层 规则审查（逐项核对）

- [ ] 排版硬规范九条全部满足（脚本已过也要人工抽核两段，含第7条段长、第9条开场铁律）
- [ ] 字数 2500 以上，章号、文件名、标题三者一致
- [ ] 承接上章章尾钩子，本章章尾留新钩子
- [ ] 与事实表无矛盾（称谓、时间、设定、人物关系）
- [ ] 覆盖的原文段落与《原文对照.md》条目一致，教义无增改曲解
- [ ] 无现代词汇、无网络梗、无翻译腔

### 第3层 人工特性对抗审查（以 AI 检测员视角通读）

用"这段文字像不像机器批量生成的"为标准通读全章，逐项确认：

- [ ] 句长有真实起伏：存在 100 字以上的长铺陈，也有十几字的短收束，不是均匀的中等句
- [ ] 段落长度不均且适配手机阅读：长短交错，有一两句话的小段，但单段不超 100 字（手机约一屏），无整屏文字墙
- [ ] 细节是"这一个"而不是"这一类"：具体的物件、动作、时间、数目（一根戒尺拍断、半个月束脩、香烧到三分之一）
- [ ] 情绪有毛边：人物会口是心非、会臊眉耷眼、会嘴硬，不做总结式心理剖白
- [ ] 无 AI 高频腔：不堆砌"不禁、仿佛、宛如、这一刻、闪过一丝"等套路词（脚本辅助）
- [ ] 无总分总作文结构：不在段首亮观点、段尾做总结，道理从场景里长出来
- [ ] 对话像人话：短、直、带火气或带笑意，不是完整的书面句子
- [ ] 比喻来自人物生活圈：教书匠的比喻不出农耕市井，不用作者全知的高级比喻
- [ ] 叙事人有口头禅式的惯用转折（说来也怪、谁知、结果、可转念一想），但同一招一章不用两次以上
- [ ] 通读一遍出声读：任何一句读起来像说明书、像总结陈词、像翻译文的，改掉

## 七、章节类型与配比（设计本章时先定型）

| 类型 | 占比 | 写法要点 |
| --- | --- | --- |
| 经文讲解章 | 约25% | 严格对应原文段落，一句不漏讲透，剧情只作容器 |
| 实修印证章 | 约35% | 把道理演成经历，听闻、实修、考验、印证闭环 |
| 人物剧情章 | 约30% | 支线与冲突服务主线，最终收束到原文脉络 |
| 日常过渡章 | 约10% | 调节节奏、立人物 |

节奏：每 6 至 8 章一个小高潮（考验或突破），每卷结尾一个大高潮。
